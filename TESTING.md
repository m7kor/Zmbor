# Testing

## Levels

1. **Unit tests** — `build/ps2xTest/ps2x_tests` (MiniTest; code generator, decoder, memory/DMA/VIF/GIF/GS, VU0/VU1,
   kernel, scheduler, IOP bridge). Run directly; exit code is the failure count.
2. **IOP emulator tests** — configure with `-DPS2X_IOP_BUILD_TESTS=ON`, then `ctest --test-dir build/ps2xIOP`.
3. **Hardware-vector tests** — unit tests whose expectations are results printed by a real PS2
   (ps2autotests, ISC license): `ps2_float_hw_vectors.inc` (EE FPU) and `ps2_mmi_hw_vectors.inc` (MMI halfword
   multiplies, regenerated by `ps2xTest/tools/gen_mmi_hw_vectors.py`). Prefer these over emulator behaviour when
   PCSX2 and hardware disagree (example: RSQRT.S with ft = 0 takes the sign of fs alone on hardware).
4. **End-to-end tests** — `ctest --test-dir build/ps2xTest -L e2e`. Each program in `ps2xTest/e2e/e2e_programs.py`
   is assembled into a guest ELF (`mips_elf.py`, no PS2 toolchain), recompiled by `ps2_recomp`, compiled with the
   runtime into `ps2x_e2e_<name>`, run with `PS2X_HIDDEN_WINDOW=1`, and checked:
   - `basic`: exit code 0 and the exact line the guest prints with its own `puts`.
   - `gs_sprite`: additionally, `PS2X_DUMP_FRAME` writes every presented frame and `check_frame.py` checks the size
     and pixel colours computed from the program's geometry.
5. **Research database** — `ctest --test-dir build/ps2xTest -R research` validates `research/` (provenance,
   honest statuses).

## Rules

- Every behaviour fix gets a test that fails with the fix reverted (checked by reverting it locally once).
- Expected values come from hardware results, then PCSX2 source, then documented behaviour — and the source is named
  in the test.
- A passing unit or end-to-end test says nothing about commercial game compatibility; that needs the game run.

## Adding an end-to-end program

Add a `program_<name>()` to `e2e_programs.py` returning the assembler and the stub list, add its expected stdout
line to `EXPECTED` (and pixels to `FRAME_EXPECTATIONS` for graphics), then `ps2x_add_e2e_program(<name> [FRAME])`
in `ps2xTest/e2e/CMakeLists.txt`.
