# Transferable architectures

- **Candidate promotion.** Preserve separate provenance for entry points, symbols, relocations, external maps, inferred targets and observed targets. Require validated byte ranges and control-flow ownership before emission. Compare precision on synthetic ELF ground truth. [web analysis](https://github.com/snuri00/ps2-web-recomp/blob/e026b971324068773eed88bf502437de9e581b6b/recomp/analysis.cpp)
- **Image-relative target identity.** Use guest address and executable image identity for missing-target traces. Replay and regenerate offline first. Define invalidation for rewritten executable pages before assessing runtime translation. [native EE live translation](https://github.com/exoteric33/ps2-native-recomp/blob/fe6505dee0001e896b6f65e8b1316722dcd9ac9b/runtime/src/ee_live.cpp)
- **Relocation provenance.** Model a relocation as a site, target section or symbol, addend and kind. Keep it visible through function discovery and emission. Compare output against paired synthetic relocatable fixtures. [N64Recomp emission](https://github.com/N64Recomp/N64Recomp/blob/598ce2080004a5672d604dceadbda436045307b7/src/recompilation.cpp)
- **Semantic boundary before a general IR.** Start with an experiment on a small instruction subset and preserve the C++ backend. Record guest PC, delay-slot state, register write masks, exception exits and memory effects. Compare with current emission for both generated size and guest outcomes. A broad IR decision waits for measurable benefit. [Existing design](../docs/architecture/NEXT_GENERATION_RECOMPILER_DESIGN.md)
- **Deterministic events.** Compare ordered EE/IOP and DMA/IRQ traces before replacing event scheduling. Treat hardware and emulator evidence as separately attributable. [PCSX2 scheduler](https://github.com/PCSX2/pcsx2/blob/695e26713be06daf8b9d05978602946b82008716/pcsx2/R5900.cpp)
